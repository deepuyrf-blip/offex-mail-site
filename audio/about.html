About Offex Audio

A small, independent set of audio tools built for people who work with voice recordings and want them to sound cleaner without learning a full editing suite.

What this site is

Offex Audio is a free, browser-based utility for cleaning up voice audio. It started from a simple, common problem: a recording is fine except for a few fixable things — the silence at the start, the hum of a fan, the noise behind a sentence, or a music bed that needs to come out. Instead of opening a desktop editor for each small job, you can handle them in one place.

The site is built and maintained by Deepu. It is deliberately simple: a few focused tools, transparent status messages, and results you can download straight away.

The tools

  • Remove Silence — trims dead air from MP3, WAV and other common formats while keeping a short, natural pause at every cut.
  • Enhance Audio — reduces steady background noise and normalises quiet speech in Light, Balanced or Strong mode.
  • Voice / BGM Isolation — separates a voice from background music using an AI stem splitter. This one is a server-side feature, so it is shown as Not connected when that processor is offline.

How it works, and your privacy

Remove Silence and Enhance Audio run entirely in your browser using the Web Audio API. Your file is decoded on your own device, processed on your own device, and never uploaded. That means the tools work offline once the page has loaded, and your recordings stay private by default.

Voice / BGM separation is different: it needs a heavier model than a browser can run comfortably, so it depends on a connected server processor. When that processor is available the site shows a green Live badge; when it is not, the badge reads Not connected and the tool explains itself rather than failing silently.

What we are not

Offex Audio is not a replacement for a full digital audio workstation. It handles the repetitive cleanup that most voice recordings need, so that when you do open a proper editor you are working with a clean starting point. Automated processing can leave small artefacts, so always review a result before publishing it.

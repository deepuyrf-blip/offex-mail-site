なぜ Discord はメール認証を求めるのか

Discord はアカウント作成と同時にメールアドレスを求めます。それはあなたが実在の人物であることを確認し、セキュリティ通知を送り、後でプロフィールを復元できるようにするためです。

Discord は通常、数分で失効する短い確認コードを送信し、新しい端末からサインインするたびに「新しいログイン」の通知も送ります。

認証の目的は、その受信箱が本物で受信可能だと証明することなので、メールを受け取れるアドレスなら何でも使えます — 使い捨てアドレスも含まれます。Discord の Temp Mail なら、仕事や家族、銀行で使うアドレスを晒すことなく、その受信可能な受信箱を手に入れられます。

Discord の Temp Mail の使い方

  1. Offex Mail を開く — すぐに使える新しい受信箱が即座に表示されます — 登録不要、パスワード不要、インストールも不要です。
  2. 使い捨てアドレスをコピーする — ページ上部に表示されたアドレスをコピーします。通常のメールアドレスと同じ見た目で、それがまさに Discord の期待するものです。
  3. Discord に貼り付ける — Discord の登録または認証を開始し、メールアドレスを求められた場所に貼り付けて、フォームを送信して確認メールを送らせます。
  4. メールを開いて確認する — 数秒以内に Discord のメールが Offex Mail の受信箱に届きます。開いて確認リンクをクリックするか、コードを Discord にコピーして戻します。

Discord のコードが届かないとき

Discord のコードが届かない場合は、まず一度だけ再送を要求し、アドレスに余分な空白を入れていないか確認してください — Discord は不正な形式のアドレスを黙って拒否します。

  • 新しいコードを要求する前に、まる 2 分待ちましょう — 混雑時には配信がキューに入ることがあります。
  • アドレスを一文字ずつ再確認しましょう。一文字でも間違えるとメールはどこにも届きません。
  • Offex Mail の受信箱を更新しましょう。新着メールは自動で表示されますが、手動更新も問題ありません。
  • もう一度コードを要求し、それでも Discord が失敗する場合は、まったく新しい使い捨てアドレスを生成しましょう。
  • Discord に入力したアドレスと一致する受信箱を見ているか確認しましょう。

Discord に Temp Mail を使うのは安全ですか？

一時的な受信箱は賢いプライバシー対策です。宣伝メールや迷惑メール、データブローカーのリストを本物のアドレスから遠ざけ、使い終われば消えてくれます。一度きりの登録やお試し、テスト用アカウントにはまさにうってつけです。

安全に保つルールは 2 つ。残したい・復元したい・支払いが必要なアカウントには Temp Mail を使わないこと — 今後 Discord に頼る予定ならそれも含まれます — そして、お試しが本番になったら必ず恒久的なアドレスに切り替えることです。

よくある質問

Temp Mail で Discord のアカウントを作れますか？
はい。Discord は確認コードを送るために受信可能な受信箱さえあればよいので、使い捨てアドレスでも登録はできます。ただし受信箱が失効すると、パスワード再設定メールを受け取れなくなる点に注意してください。
Discord の認証メールはどれくらいで届きますか？
通常は 1 分以内に届きます。2 分たっても何も届かない場合は、新しいコードを要求し、入力したアドレスのつづりを正確に確認してください。
Discord で「メールが既に使用されています」と言われるのはなぜですか？
そのアドレスは以前に別のアカウントに紐づけられていました。新しい使い捨て受信箱を生成して再試行してください — まったく新しいアドレスなら「既に使用中」のエラーは必ず解消します。
一時的なメールで Discord を認証するのは安全ですか？
使い捨てやテスト用のアカウントなら問題ありません。メインの Discord プロフィールには、いつでもパスワードを再設定できるよう、恒久的に管理できるアドレスを使ってください。
